# Product Roadmap v7

**Date:** August 10, 2026  
**Author:** Priya Raman, Chief Product Officer

## Northstar Flow 2.4

Northstar Flow 2.4 is the next major product release.

### Planned capabilities

- Expanded workflow analytics
- Improved audit logs
- Additional permission controls
- Salesforce workflow improvements
- Improved workflow failure diagnostics

## Launch target

The original target launch date for version 2.4 was **September 5, 2026**.

The release is in final testing.

Security validation is a launch requirement.

No release date should be considered final until security testing is complete.

The roadmap therefore treats September 5 as the current planning target rather than a guaranteed release date.
